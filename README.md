# 贝拉卡斗场

一个适合三个人共用一部手机的 1V1 动漫卡牌小游戏：两位玩家秘密抽卡，第三人担任裁判公开对战。

## 对局规则

1. 点击「开始一局」，系统从 43 张卡池中为玩家 A、B 各发 6 张卡；CSP 冠冕卡每局最多出现 1 张。
2. 玩家 A 转身查看自己的 6 张牌，选择 4 张并按点击顺序锁定；随后把手机交给玩家 B 重复一次。
3. 裁判按顺序公开第 1～4 张卡。每局点击「开始战斗」，双方卡牌以固定基础数值自动扣血。
4. 每次伤害为 `max(5, 攻击力 - 对方防御力)`，先把对方生命扣到 0 的一方赢下该局；四局中胜局更多的一方获胜，2:2 时判平局。

## 卡池稀有度

标准卡池按“等级越高数量越少”安排：R 15、SR 9、SSR 6、UR 4、HR 3、LGR 2、SP 1；另有 3 张 CSP 特别卡（芙宁娜、贝拉·问剑、芊辰）。

## 本地运行

```bash
npm install
npm run dev:fixed
```

打开 `http://127.0.0.1:55174/` 即可开始试玩；`npm run build` 用于生成生产构建。
