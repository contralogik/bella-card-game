# 贝拉卡斗场

一个适合三个人共用一部手机的 1V1 动漫卡牌小游戏：两位玩家秘密逐张揭牌，第三人担任裁判公开对战。

## 对局规则

1. 点击「开始一局」，1V1 模式为双方各发 8 张，团战模式为双方各发 10 张；每局从 54 张牌中无放回洗牌，每张牌抽到的概率相同。
2. 两个阵营交替揭牌：贝拉揭一张、芊辰揭一张，直到双方全部抽完；抽卡阶段不提前选牌，之后再分别选择 5 张（1V1）或 7 张（团战）。1V1 的点击顺序就是五局出场顺序，团战顺序随机。
3. 裁判按顺序公开第 1～5 张卡。每局点击「开始战斗」，双方卡牌以固定基础数值自动扣血。
4. 每次伤害为 `max(5, 攻击力 - 对方防御力)`，先把对方生命扣到 0 的一方赢下该局；五局中胜局更多的一方获胜，胜局相同时比较剩余生命。
5. 游戏使用浏览器实时合成背景音乐、翻牌声、选牌声和战斗碰撞声，可随时用右上角按钮静音。

## 卡池稀有度

当前卡池分布为：R 15、SR 9、SSR 8、UR 4、HR 5、LGR 8、SP 2；另有 3 张 CSP 特别卡（芙宁娜、贝拉·问剑、芊辰）。新增唐僧、名侦探柯南、光明皇帝、水兵月、孙悟空·七龙珠、迪迦奥特曼、奶龙。

## 本地运行

```bash
npm install
npm run dev:fixed
```

打开 `http://127.0.0.1:55174/` 即可开始试玩；`npm run build` 用于生成生产构建。
