# 贝拉卡斗场

一个适合三个人共用一部手机的 1V1 动漫卡牌小游戏：两位玩家秘密逐张揭牌，第三人担任裁判公开对战。

## 对局规则

1. 点击「开始一局」，系统从 47 张卡池中为贝拉阵营、芊辰阵营各发 8 张卡；CSP 冠冕卡每局最多出现 1 张。
2. 贝拉阵营每次只在手机屏幕上揭晓 1 张卡，连续看完 8 张后选择 5 张；点击顺序就是五局的出场顺序。随后把手机交给芊辰阵营重复一次。
3. 裁判按顺序公开第 1～5 张卡。每局点击「开始战斗」，双方卡牌以固定基础数值自动扣血。
4. 每次伤害为 `max(5, 攻击力 - 对方防御力)`，先把对方生命扣到 0 的一方赢下该局；五局中胜局更多的一方获胜，胜局相同时比较剩余生命。
5. 游戏使用浏览器实时合成背景音乐、翻牌声、选牌声和战斗碰撞声，可随时用右上角按钮静音。

## 卡池稀有度

标准卡池按“等级越高数量越少”安排：R 15、SR 9、SSR 6、UR 4、HR 4、LGR 5、SP 1；另有 3 张 CSP 特别卡（芙宁娜、贝拉·问剑、芊辰）。新增玛薇卡、安娜丝塔夏、哥伦比娅为 LGR，桑多涅为 HR。

## 本地运行

```bash
npm install
npm run dev:fixed
```

打开 `http://127.0.0.1:55174/` 即可开始试玩；`npm run build` 用于生成生产构建。
