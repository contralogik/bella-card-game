# 贝拉卡斗场

一个适合三个人共用一部手机的 1V1 动漫卡牌小游戏：两位玩家秘密逐张揭牌，第三人担任裁判公开对战。

## 对局规则

1. 点击「开始一局」，1V1 模式为双方各发 8 张，团战模式为双方各发 10 张，命运事件赛为双方各发 5 张；每局从 77 张牌中无放回洗牌，每张牌抽到的概率相同。
2. 两个阵营交替揭牌：贝拉揭一张、芊辰揭一张，直到双方全部抽完；抽卡阶段不提前选牌，之后再分别选择 5 张（1V1）、7 张（团战）或 3 张（命运事件赛）。1V1 与事件赛的点击顺序就是出场顺序，团战顺序随机。
3. 1V1 裁判按顺序公开第 1～5 张卡；团战逐组公开当前双方卡牌；命运事件赛进行 3 局，每局先公开一条命运事件和一张公共战术牌，再公开双方角色卡。
4. 基础伤害为 `max(5, 攻击力 - 对方防御力)`。1V1 与命运事件赛先把对方生命扣到 0 的一方赢下该局；1V1 五局或事件赛三局中胜局更多的一方获胜，胜局相同时比较剩余生命。事件赛的命运事件和公共战术牌只改变本局的攻击、防御、伤害结算，不需要修改人物卡图。
5. 团战中当前卡牌生命归零后才换下一张，击败一张卡的幸存者额外扣除自身最大生命值的 20% 作为连续作战疲劳；一队 7 张卡全部出局即告负。
6. 游戏循环播放 `siege_of_the_sun_gates.mp3` 作为背景音乐，翻牌声、选牌声和战斗碰撞声由浏览器合成；可随时用右上角按钮静音。

## 卡池稀有度

当前卡池分布为：R 15、SR 9、SSR 12、UR 13、HR 10、LGR 13、SP 2；另有 3 张 CSP 特别卡（芙宁娜、贝拉·问剑、芊辰）。本次新增五条悟、利威尔、樱木花道、阿尼亚、灶门祢豆子、米老鼠、蜘蛛侠、汪汪队阿奇、超人、蝙蝠侠、胡桃、纳西妲。

所有抽卡阶段的卡背统一使用 `card-back-contralogik.png`，正面揭晓后才显示角色卡面。

命运事件赛的公共战术牌使用统一的动漫道具牌面 `public/cards/tactic-common.png`，战术名称和效果由网页叠加显示。

## 本地运行

```bash
npm install
npm run dev:fixed
```

打开 `http://127.0.0.1:55174/` 即可开始试玩；`npm run build` 用于生成生产构建。
